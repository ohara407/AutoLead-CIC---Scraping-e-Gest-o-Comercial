# 📋 Estrutura do Formulário de Feedback (App-CIC)

> [!abstract] Objetivo do Formulário
> Coletar métricas reais de uso, usabilidade no balcão e pontos de atrito no **App-CIC** para direcionar o roadmap de engenharia e criar base de prova social para futuras vendas.
> Recomendação de ferramentas gratuitas: **Tally.so**, **Google Forms** ou **Typeform**.

---

## 📝 Seções e Perguntas do Formulário

### Seção 1: Identificação Básica
1. **Nome do Comércio:** *(Resposta curta - Ex: Hortifruti do Cocaia)*
2. **Seu Nome e Cargo:** *(Resposta curta - Ex: Gilberto, Proprietário)*
3. **WhatsApp para Contato:** *(Número com DDD)*
4. **Bairro / Cidade:** *(Ex: Jardim Cocaia - Guarulhos, SP)*

---

### Seção 2: Experiência e Usabilidade no Balcão
5. **De 0 a 10, quão fácil foi registrar saídas de produtos no celular durante o movimento?**
   - Escala linear (0 = Muito difícil / 10 = Extremamente fácil e rápido)
6. **O alerta de estoque baixo (alerta vermelho/amarelo) ajudou a saber a hora de repor mercadoria?**
   - ( ) Sim, evitou que faltasse produto no balcão
   - ( ) Ajudou moderadamente
   - ( ) Não utilizei essa função
   - ( ) Outro: [campo aberto]
7. **Quanto tempo por dia você calcula que economizou ou organizou melhor com o App-CIC?**
   - ( ) Menos de 15 minutos
   - ( ) Entre 15 e 30 minutos
   - ( ) Mais de 1 hora por dia
   - ( ) Ainda estou me adaptando

---

### Seção 3: Melhorias e Sugestões do Comerciante (Ouro do Produto)
8. **Qual funcionalidade fez mais falta para o dia a dia do seu comércio?**
   - [ ] Leitor de código de barras pela câmera do celular
   - [ ] Impressão de comprovante em maquininha térmica Bluetooth
   - [ ] Cadastro de fiado / clientes recorrentes
   - [ ] Integração com Pix e pagamentos
   - [ ] Outro: [campo aberto]
9. **O que você mais gostou no aplicativo?** *(Texto longo)*
10. **O que quase te fez desistir de usar ou achou confuso?** *(Texto longo)*

---

### Seção 4: O Gancho para o Site & Parceria Contínua
11. **Seus clientes já perguntaram se você tem cardápio digital ou catálogo de produtos na internet para pedir por WhatsApp?**
    - ( ) Sim, direto perguntam
    - ( ) Às vezes
    - ( ) Gostaria muito de ter um site próprio para o meu comércio
    - ( ) Não tenho interesse no momento
12. **De 0 a 10, qual a probabilidade de você recomendar o App-CIC para outro comerciante do bairro?** *(NPS)*

---

## 📊 Como Utilizar as Respostas

1. **Nota NPS >= 9**: Pedir autorização para usar o depoimento no site oficial e ligar imediatamente para apresentar a proposta do site profissional.
2. **Nota NPS <= 6**: Entrar em contato via WhatsApp oferecendo suporte prioritário e ajustando o produto para sanar a dor apontada.
3. **Respostas da Pergunta 11**: Leads quentes e prontos para fechamento imediato da criação de site express!
